# Suas fotografias

1. Copie suas fotos para esta pasta.
2. Atualize a página no navegador.

Pronto: o portfólio lê os arquivos, identifica as dimensões e substitui as fotos
de demonstração automaticamente. Não é preciso editar código.

Formatos: JPG, JPEG, PNG, WebP e AVIF. A extensão pode estar em maiúsculas.

O nome do arquivo vira o título e o texto alternativo da imagem. Use nomes
descritivos, por exemplo: `01 - Barcos no lago.jpg`, `02 - Rua ao entardecer.webp`.
O número inicial define a ordem e não aparece no título. Sem números, a ordem é
alfabética. Você também pode usar subpastas para organizar coleções.

Para remover uma foto, tire o arquivo desta pasta e atualize a página.
Se a pasta ficar vazia, as imagens de demonstração voltam automaticamente.

O layout funciona com uma foto, poucas fotos ou uma coleção maior. Todas aparecem
na galeria em grid, preservando as proporções originais. Novos lotes entram
automaticamente durante a rolagem; clique ou toque em qualquer foto para ampliar.

No site publicado, é necessário enviar os arquivos junto do projeto e publicar
uma nova versão (`npm run build`). Copiar arquivos no seu computador não altera
automaticamente o site hospedado. A pasta é pública: publique apenas as fotos que
você deseja disponibilizar aos visitantes.
