# Developer project selection

The current project data in `content/duality.ts` contains LEIA, Formazzi and
Blitz. The selection is a four-column editorial table: project, focus,
technologies and view. It uses a white surface, muted uppercase headers, large
project names and thin horizontal rules, matching the supplied reference image.

Selecting a project name or its arrow opens the existing case study. Keep that
detail presentation independent from the table styling. Build focus labels from
the discipline data and technologies from the project stack. Do not fabricate
client, location or year metadata that is not present in the records.

On narrow screens, retain the table's four-column hierarchy with smaller type
and wrapped cell content; prevent horizontal overflow. Use keyboard-visible
focus and honor reduced motion.
